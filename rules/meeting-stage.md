# 会議の段階に合わせる

資料を作る前に、その会議が「イメージ合わせ」「論点整理」「意思決定」のどの段階かを確かめ、その段階のページだけを作る。
**Why:** 目指す姿の像が揃う前に論点（単位・様式・導入順）を出すと、議論が手段に流れ、像の合意ができない。イメージ合わせの資料に論点表と意思決定事項を入れ、「このタイミングでは早い」と指摘された。

## イメージ合わせの資料（目指す業務の見せ方）
- 1件1ページ。冒頭に「何を実現したいか」を1行で置く
- 上段に「データ → ロジック → 画面に出る結果」を横に並べて丸数字を振る。データは図形（円柱）、ロジックは値のタイルと演算子を並べた式の図で示す
- ロジックは閾値・係数まで書かず、「何と何を比べて／掛け合わせて、何を出すか」の概念で示す
- 下段に試作アプリの画面の該当部分を横幅いっぱいに大きく切り出し、同じ丸数字で対応づける。番号・枠線は画面の文字に重ねない（余白に置いて線でつなぐ）
- 直すたびに、画面の大きさが前の版より小さくなっていないかを確かめる
- 領域の全体ページには業務フローを置かず、「現状の課題 → 実現したいこと」を簡潔に置く
- ダミーデータの断り書き、数値の具体例の文章、業務の場面・人の判断の箱は載せない
- 論点は「次のステップ」に1行で置くにとどめる
