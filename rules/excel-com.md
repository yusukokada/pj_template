# Excel の操作

## 1. 人が作った Excel は COM で編集し、openpyxl は読むだけにする
条件付き書式の拡張・シート保護・図形（ER 図など）を持つ Excel は、openpyxl で保存すると、それらが黙って消える。pywin32 の Excel COM で編集する。
- 例外：`doc_tools/definition.py` が作るデータ定義書は、拡張も図形も持たない形にしてあるので openpyxl で作る
**Why:** openpyxl で保存して、条件付き書式と ER 図が消えたことがある。

## 2. COM の注意
- 引数は位置で渡す。キーワード引数は黙って無視されることがある（`Protect`、`FormatConditions.Add(2, 1, 式)`、`Copy(None, sheet)` など）
- 日付は Excel のシリアル値で書く。datetime を渡すと時差で前日になる
- `Range.Replace` は配列数式（{ }）を普通の数式に変え、SUMPRODUCT(IFERROR(...)) などが黙って 0 を返す。置換の前に配列数式のセルと式を控え、置換の後に `Range.Formula2` で入れ直す
- 数式の行範囲を一括で置き換えるときは、行番号まで含めない（$P2 は2行目にしか当たらない）
- 列を挿すと、ほかのシートの VLOOKUP の列番号がずれる。旧→新の列の対応表を作って、数式の参照を機械的に張り替える
- `Hyperlinks.Add` の TextToDisplay は効かないので、後から Value を入れる

## 3. 保存の前に表示を整える
全シートで A1 を選び、左上へスクロールし、最初に見せるシートを選んでから保存する。
**Why:** 開いたときに途中のセルやシートが表示されていると、受け取った人が迷う。

## 4. 確かめ方
版を上げたら、旧版と新版を COM で両方開き、合計値・件数・判定の分布が意図どおりに変わったか（または変わっていないか）を比べる。Excel を開いたまま（`~$` で始まるファイルがある状態で）スクリプトを流さない。
