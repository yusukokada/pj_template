# このプロジェクト固有のルール・決定

プロジェクトを始めたら、ここに足していく。どのプロジェクトでも効くものは `rules/` 直下に書く。

## 書き方
1つのファイルに1つのテーマ。ファイル名は英小文字とハイフン（例：`scope-decisions.md`）。

```markdown
# （テーマ）

（決まったこと・ルール）
**Why:** （理由。ユーザーの指摘ならその言葉と日付）
**How to apply:** （次からどうするか）
```

書いたら、下の一覧に1行足す。決定が変わったら、古い記述を消して書き直す（両方残さない）。

## 一覧
- （まだない）
